# Diabetes Prediction using Machine Learning

## Project Description
This project predicts whether a person has diabetes or not using machine learning. 
The model is trained on the Pima Indians Diabetes dataset which contains medical 
information such as glucose level, blood pressure, BMI, insulin level, age, etc.

The objective of the project is to build a classification model that can take 
patient health data as input and predict the possibility of diabetes.

## Dataset
The dataset contains the following attributes:

Pregnancies – Number of times pregnant  
Glucose – Plasma glucose concentration  
BloodPressure – Diastolic blood pressure  
SkinThickness – Triceps skin fold thickness  
Insulin – Serum insulin level  
BMI – Body Mass Index  
DiabetesPedigreeFunction – Diabetes hereditary score  
Age – Age of the patient  
Outcome – Target variable (0 = Non-diabetic, 1 = Diabetic)
