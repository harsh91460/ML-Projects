# Rock vs Mine Prediction using Machine Learning

## Project Description

This project uses machine learning to classify sonar signals as either a rock or a mine. The model is trained on the Sonar dataset which contains signals bounced off metal cylinders (mines) and rocks under water.

The objective of the project is to build a classification model that can correctly identify whether the object detected by sonar is a rock or a mine.

## Dataset

The dataset used in this project is the Sonar dataset.

Each row represents sonar signal readings. The dataset contains 60 numerical attributes that represent energy values of sonar signals at different frequencies.

Target Variable:

R – Rock
M – Mine

## Project Workflow

1. Importing the dataset
2. Data preprocessing

## Model Usage

The trained model can take sonar signal values as input and predict whether the object is a rock or a mine.
