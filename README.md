# Machine Learning Projects

This repository contains multiple Machine Learning projects implemented using Python and popular ML libraries. These projects demonstrate practical knowledge of data preprocessing, model training, and prediction systems.

---

## Projects Included

### 1. Diabetes Prediction

A machine learning model that predicts whether a person has diabetes based on medical attributes.

**Features**
- Data preprocessing and cleaning
- Model training and evaluation
- Diabetes prediction based on input health parameters

**Technologies Used**
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

**Dataset**
Pima Indians Diabetes Dataset

---

### 2. Rock vs Mine Prediction

This project classifies sonar signals as either **rock** or **mine** using a machine learning classification model.

**Features**
- Binary classification problem
- Feature analysis of sonar signals
- Model training and prediction

**Technologies Used**
- Python
- Pandas
- NumPy
- Scikit-learn

**Dataset**
Sonar Dataset

---

### 3. Spam Mail Detection

A machine learning model that detects whether an email message is **spam** or **ham (not spam)** using Natural Language Processing techniques.

**Features**
- Text preprocessing
- Feature extraction using TF-IDF
- Spam classification

**Technologies Used**
- Python
- Pandas
- Scikit-learn
- NLP Techniques

**Dataset**
Spam Email Dataset
